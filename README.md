# 🎮 Operación Extracción: Sobrevive al Apocalipsis (FPS 3D)

## Descripción del Juego
Videojuego tridimensional en primera persona (First-Person Shooter) desarrollado con **Three.js / WebGL**. El jugador debe atravesar un corredor infestado de zombis, administrar su munición limitada entre dos armas diferentes, recolectar suministros en el camino y alcanzar la plataforma luminosa de extracción al final del recorrido antes de ser atrapado.
